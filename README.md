## Heart Disease Prediction
This project uses logistic regression to predict heart disease based on the Heart Disease UCI dataset from Kaggle.
## Overview
The goal is to predict whether a patient has heart disease using features like age, cholesterol, and blood pressure. Key steps include:

Data Preprocessing: Cleaned data and encoded categorical features.
Model Training: Built a logistic regression model with scikit-learn.
Evaluation: Measured performance using accuracy and log loss (cost function).
Findings: The model accurately predicts heart disease with a low log loss.

## Repository Contents

Heart_Disease_Prediction.ipynb: Kaggle Notebook with the complete code and analysis.
